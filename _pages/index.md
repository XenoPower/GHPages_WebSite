# はじめに
私の好きなゲームは**Overwatch**である。Overwatchは難しい、民度が低いなどといった意見をよく目にするが、実は幅広い人に刺さるポテンシャルのあるゲームであるということを語ろうと思う。
# Overwatchとは
Overwatchの魅力は
- 完成された世界観
- 刺激的な演出
- 奥深いゲーム性
- FPSが得意でない人も輝ける  

にある。順を追って説明しよう。  
1. 完成された世界観  
Overwatchの舞台は、AIが人類に対して反逆し、戦争があった後の未来である。その戦争に便乗して悪さをする人間や、AIの中にも戦争に反対するものがいたりなど、一辺倒ではないリアリティのある世界観が魅力である。
![image](/GHPages_WebSite/assets/images/omnic.png)
3. 刺激的な演出  
操作できるキャラクターはヒーローと呼ばれる。ヒーローという名の通り攻撃、スキルの演出などが派手で、勝敗に関わらず楽しくプレイできる。FPSにしては珍しく音楽もあり、その音楽もまた人気を博している。  
4. 奥深いゲーム性  
Overwatchではエリアを確保する、オブジェクトをゴールまで運ぶなどが勝利の条件であり、敵を倒すことが勝利の条件ではない。そのため、ゲームルールの深い理解が勝利に繋がる。またヒーローの個性が豊かで相性の良いヒーロー、悪いヒーローがおり、将棋のような駆け引きが展開される。
5. FPSが得意でない人も輝ける  
Overwatchではヒーローごとに固有のスキルがあり、その使い方が勝敗を左右すると言っても過言ではない。そのため、エイムに自信がない人もスキルの使い方次第でチームを導きうるのだ。  
# 総括  
このようにOverwatchには様々な人に刺さる魅力を多く持ったゲームである。Overwatchでのチームワークを通じて友人との仲を深めてみてはどうだろうか。
